
# GPU Comparison

## Опис проєкту

GPU Comparison — створений для порівняння характеристик різних відеокарт.

Мета проєкту — практичне використання HTML та CSS,
створення семантичних таблиць і робота з локальними шрифтами.

## Використані технології

- HTML5
- CSS3
- @font-face
- WOFF2
- Семантична HTML-таблиця
- GitHub Pages

## Структура проєкту

- index.html — основна сторінка.
- style.css — оформлення сторінки.
- fonts/ — локальні шрифти.

## Перевірка браузера

Сторінку фактично перевірено у [Microsoft Edge].

Друге середовище, порівняння не виконувалося.

Локальний шрифт завантажується коректно,
таблиця та контентний контейнер відображаються стабільно.
